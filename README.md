#TDZ
TDZ (Минтақаи муваққатии мурда) дар JavaScript як ҳолатест, ки тағйирёбандаҳо пеш аз инициализатсия (яъне додани қимат) истифода намешаванд.

Масъала:
Агар мо let ё const-ро пеш аз таърифи онҳо истифода барем, хатои ReferenceError пайдо мешавад.

Мисоли TDZ бо let ва const
Дар ин ҷо, JavaScript тағйирёбандаро hoist мекунад, вале пеш аз инициализатсия онро дар TDZ нигоҳ медорад.

Чаро var бо TDZ мушкил надорад?

var низ hoist мешавад, вале он ба TDZ дохил намешавад. Ба ҷои ин, он ба таври худкор undefined мегирад:
Дар ин ҷо, var y; ба боло мебарояд ва ба он undefined дода мешавад, бинобар ин, мо хатои ReferenceError намегирем.

TDZ бо функсияҳо

Агар функсияро бо function таъриф кунем, он ба боло мебарояд ва TDZ надорад:


Вале агар функсия ҳамчун expression бо let ё const таъриф шуда бошад, он ба TDZ дохил мешавад:



Дар ин ҳолат, greet дар TDZ қарор дорад ва истифода бурданаш пеш аз инициализатсия мумкин нест.

Хулоса

1. TDZ ба let ва const таъсир мерасонад, на ба var.


2. Агар тағйирёбанда дар TDZ бошад ва пеш аз инициализатсия истифода шавад, ReferenceError мегирем.


3. Функсияҳои анъанавӣ (function) TDZ надоранд, вале function expressions бо let ё const ба TDZ дохил мешаванд.

TDZ кӯмак мекунад, ки хатогиҳо ҳангоми истифодаи тағйирёбандаҳои инициализатсиянашуда пешгирӣ шаванд ва барномаи мо устувортар гардад.
